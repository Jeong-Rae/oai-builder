## 레이어와 고정 배치

Chapter 화면은 배경, 별자리 카드 트랙, 달, 고양이와 조작 요소 순으로 쌓입니다. 달과 고양이는 Chapter가 바뀌어도 고정되며 별자리 카드 트랙만 수평으로 이동합니다.

| 요소 | Figma 좌표 `(x, y)` | Figma 크기 | 화면 대비 배치 |
|---|---:|---:|---:|
| 타원형 달 | `(-717, 742)` | `1573×1049` | `left: -37.344%`, `top: 68.704%`, `width: 81.927%` |
| 고양이 | `(329, 617)` | `308×308` | `left: 17.135%`, `top: 57.130%`, `width: 16.042%` |
| 고양이 그림자 | `(96, 885)` | `157×40` | `left: 5%`, `top: 81.944%`, `width: 8.177%` |
| 선택 카드 | `(721, 262)` | `478×560` | 중심점 `(960, 542)` |
| 제목 텍스트 상자 | `(536, 66)` | `847×96` | 가로 중심 `959.5` |

달의 노드 경계는 화면 안에서 `x=0~856`, `y=742~1080`만 보입니다. 고양이는 달과 세로 방향으로 183px 겹치며 달보다 위에 렌더링됩니다. 고양이 오른쪽과 선택 카드 왼쪽 사이에는 84px의 여백이 있습니다. 달과 선택 카드의 노드 경계는 가로 135px, 세로 80px만큼 겹치므로 달이 좌측 전경과 중앙 선택 영역을 이어 줍니다.

제목과 선택 카드는 화면의 정확한 가로 중앙선인 `x=960`을 공유합니다. 고양이 중심 `(483, 771)`에서 선택 카드 중심 `(960, 542)`으로 이어지는 시선은 오른쪽으로 477px, 위로 229px 이동하는 대각선을 형성합니다.

## 별자리 카드 트랙

선택 카드는 478×560이며 비활성 카드는 384×450입니다. 비활성 카드 배율은 선택 카드 대비 약 `0.80335`입니다. 두 상태는 아래쪽 기준선 `y=822`에 맞춰 정렬합니다.

| 선택 상태 | 트랙 X | 선택 카드의 트랙 내부 X | 선택 카드의 화면 X |
|---|---:|---:|---:|
| Aries | `721` | `0` | `721` |
| Taurus | `257` | `464` | `721` |
| Gemini | `-207` | `928` | `721` |
| Cancer | `-671` | `1392` | `721` |

트랙은 Chapter가 하나 이동할 때마다 464px씩 이동합니다. 구현에서는 다섯 개 재사용 슬롯을 다음 중심 위치에 배치하여 같은 관계를 유지합니다.

| 슬롯 | 중심 X | 화면 너비 대비 위치 |
|---|---:|---:|
| 화면 밖 왼쪽 | `-15` | `-0.78125%` |
| 이전 | `449` | `23.38542%` |
| 현재 | `960` | `50%` |
| 다음 | `1471` | `76.61458%` |
| 화면 밖 오른쪽 | `1935` | `100.78125%` |

선택 카드 내부에서는 별자리 그림을 위쪽에 두고 Zodiac 기호를 카드의 가로 중앙 아래쪽에 둡니다. 선택 상태는 금색, 비활성 상태는 회색으로 구분합니다. 진행 상태를 나타내는 별 노드 색상은 현재 선택 카드에서만 유지하고, 비활성 카드의 별과 연결선은 회색으로 표시합니다.

## 코드 반영 원칙

1. 1920×1080을 논리 좌표계로 삼고 모든 위치와 크기를 백분율로 변환합니다.
2. `.game-frame`이 화면 밖의 달과 카드 트랙을 잘라내도록 `overflow: hidden`을 유지합니다.
3. 기존 DOM 슬롯 재사용과 키보드 탐색을 유지하며 새로운 캐러셀 의존성을 추가하지 않습니다.
4. 기존 WebP 자산을 재사용합니다. 달은 원형 자산 대신 투명 여백을 제거한 `moon.eclipse.trimmed.webp`를 사용합니다.
5. 움직임 감소 설정에서는 기존 전역 규칙에 따라 전환 시간을 최소화합니다.

## 검증 기준

- 선택 카드가 모든 Chapter에서 화면 중앙 `x=960`을 유지해야 합니다.
- 선택 카드는 478×560, 비활성 카드는 약 384×450으로 렌더링되어야 합니다.
- 달과 고양이는 Chapter 이동 중에 움직이지 않아야 합니다.
- 고양이는 `(329, 617)`과 `308×308`에 대응하는 비율로 배치되어야 합니다.
- 첫 Chapter에서는 이전 화살표가, 마지막 Chapter에서는 다음 화살표가 비활성화되어야 합니다.
- 키보드 좌우 방향키와 카드 클릭 동작이 기존과 동일하게 작동해야 합니다.
- 16:9 화면에서 Figma 기준 스크린샷과 시각적으로 비교하고, 타입 검사·자동 테스트·프로덕션 빌드를 통과해야 합니다.
