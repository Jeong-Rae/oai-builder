# 일반 오브젝트

`OBJ-NORMAL` · 노멀 오브젝트

컨트롤을 소유하고 소유한 방향으로 이동하는 노멀 오브젝트. 충돌 시에는 대상의 종류와 상태에 따라 컨트롤을 전달·수신·교환한다.

## 기본 정보

| 항목     | 값               |
| ------ | --------------- |
| 블록명    | 일반 오브젝트        |
| 식별자    | `OBJ-NORMAL`    |
| 키      | `object.normal` |
| 타입     | 노멀              |
| 이동 여부  | 가능 — 소유한 컨트롤 방향으로 1칸 |
| 블록 이미지 | <!-- 작성 -->     |
| 이동 단위  | 1칸              |

## 소유권

| 컨트롤 | 참조           |
| --- | ------------ |
| ↑   | `CTRL-UP`    |
| ↓   | `CTRL-DOWN`  |
| ←   | `CTRL-LEFT`  |
| →   | `CTRL-RIGHT` |

소유한 컨트롤이 입력되면 해당 방향의 행동 주체가 된다.

## 충돌 상호작용

| 충돌 대상 | 조건 | 동작 | 결과 |
|---|---|---|---|
| 비점유 타일 | 소유한 컨트롤 입력 | 이동 | 해당 방향으로 1칸 이동 |
| 노멀 오브젝트 | 충돌 | 컨트롤 전달 | 양쪽 위치를 유지하고, 사용한 컨트롤을 대상에게 전달 |
| 빈 앵커 | 충돌 | 컨트롤 전달 | 양쪽 위치를 유지하고, 사용한 컨트롤을 앵커에게 전달 |
| 컨트롤을 보유한 앵커 | 충돌 | 컨트롤 집합 수신 | 양쪽 위치를 유지하고, 앵커의 컨트롤 집합 전체를 받음 |
| 스와퍼 | 충돌 | 컨트롤 집합 교환 | 양쪽 위치를 유지하고, 두 컨트롤 집합 전체를 교환 |

## 관계

| 대상           | 관계         | 결과         |
| ------------ | ---------- | ---------- |
| 노멀 오브젝트 | `transfer` | 사용한 컨트롤 전달 |
| 앵커 | `anchor` | 앵커 상태에 따라 수신 또는 전량 전달 |
| 스와퍼 | `swap` | 컨트롤 집합 전체 교환 |
