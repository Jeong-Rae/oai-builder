# 게이트

`FIELD-GATE` · 필드

연결된 모든 플레이트가 활성화되면 열리는 고정형 필드.

## 기본 정보

| 항목 | 값 |
|---|---|
| 블록명 | 게이트 |
| 식별자 | `FIELD-GATE` |
| 키 | `field.gate` |
| 블록 이미지 | <!-- 작성 --> |
| 활성화 대상 | 연결된 `FIELD-PLATE` N개 |
| 이동 여부 | 고정형 필드 |
| 맵 내 존재 수 | 최대 1개 |

## 상태

| 상태 | 키 | 조건 |
|---|---|---|
| 닫힘 | `closed` | 연결된 플레이트 중 하나 이상이 `inactive` |
| 열림 | `open` | 연결된 모든 플레이트가 `active` |

## 동작

| 조건 | 동작 | 결과 |
|---|---|---|
| 마지막 비활성 플레이트 활성화 | 열기 | 게이트가 `open` |
| 활성 플레이트 중 하나 비활성화 | 닫기 | 게이트가 `closed` |
| 오브젝트가 닫힌 게이트로 진입 | 이동 거절 | 진입 전 위치 유지 |
| 오브젝트가 열린 게이트로 진입 | 이동 허용 | 게이트 필드 점유 |

## 관계

| 대상 | 관계 | 결과 |
|---|---|---|
| `FIELD-PLATE` N개 | `activator` | 연결된 모든 플레이트가 활성화되면 게이트 열림 |
| 오브젝트 | `block/pass` | 게이트 상태에 따라 진입 거절 또는 허용 |

## 규칙

- `FIELD-GATE`는 이동하거나 밀리지 않는다.
- 하나의 맵에는 `FIELD-GATE`가 최대 1개만 존재할 수 있다.
- `FIELD-GATE`는 N개의 `FIELD-PLATE`와 연결될 수 있다.
- 플레이어가 플레이트를 점유해도 게이트는 열리지 않는다.
- 연결된 모든 플레이트가 일반 오브젝트에 의해 활성화되어야 게이트가 열린다.

## 시각 표현

| 상태 또는 이벤트 | 표현 |
|---|---|
| `closed` | 통과할 수 없는 닫힌 게이트 |
| `open` | 통과할 수 있는 열린 게이트 |

## 참조

- `FIELD-PLATE` — 게이트 활성화 필드
- `OBJ-NORMAL` — 플레이트 활성화 오브젝트

## 규칙 근거

- 사용자 정의 규칙 · 맵당 게이트 1개, 모든 연결 플레이트 활성화 시 게이트 개방
