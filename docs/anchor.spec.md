# 앵커

`OBJ-ANCHOR` · 스페셜 오브젝트

제자리에 고정된 스페셜 오브젝트. 충돌한 상호작용 오브젝트와 컨트롤을 주고받되, 앵커 자신은 이동하지 않는다.

## 소유권

앵커는 컨트롤 집합을 소유할 수 있다. 컨트롤의 소유 여부는 충돌 시의 행동을 결정한다.

| 컨트롤 | 참조 |
|---|---|
| ↑ | `CTRL-UP` |
| ↓ | `CTRL-DOWN` |
| ← | `CTRL-LEFT` |
| → | `CTRL-RIGHT` |

## 충돌 상호작용

앵커가 다른 오브젝트와 충돌하면, 두 오브젝트는 현재 위치를 유지한다. 앵커의 컨트롤 집합 상태에 따라 다음 동작을 수행한다.

| 앵커 상태 | 충돌 조건 | 동작 | 결과 |
|---|---|---|
| 비어 있음 | 상호작용 오브젝트가 앵커에 충돌 | 컨트롤 수신 | 상호작용에 사용한 컨트롤의 소유자가 앵커로 변경됨 |
| 컨트롤 보유 | 상호작용 오브젝트가 앵커에 충돌 | 컨트롤 집합 전달 | 앵커의 컨트롤 집합 전체가 상호작용 오브젝트에게 전달되고, 앵커의 컨트롤 집합은 비워짐 |

## 관계

| 대상 | 관계 | 결과 |
|---|---|---|
| 상호작용 오브젝트 | `anchor` | 앵커 상태에 따라 컨트롤 수신 또는 전량 전달 |

## 예시

### 빈 앵커가 컨트롤을 받는 경우

Before: `BLOCK [↑] → ANCHOR []`

After: `BLOCK [] → ANCHOR [↑]`

### 컨트롤을 보유한 앵커가 전부 주는 경우

Before: `BLOCK [↑] → ANCHOR [→ ←]`

After: `BLOCK [↑ → ←] → ANCHOR []`
