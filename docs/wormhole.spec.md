# 웜홀

`FIELD-WORMHOLE` · 필드

진입한 오브젝트를 고정된 반대편 웜홀 위치로 이동시키는 필드.

## 기본 정보

| 항목        | 값                                                        |
| ----------- | --------------------------------------------------------- |
| 블록명      | 웜홀                                                      |
| 식별자      | `FIELD-WORMHOLE`                                          |
| 키          | `field.wormhole`                                          |
| 블록 이미지 | <!-- 작성 -->                                             |
| 연결 방식   | 쌍 식별자별로 고정된 `1:1` 쌍                             |
| 배치 수량   | `0`개 또는 완성된 쌍 `N`개                                |
| 쌍 이미지   | `wormhole.color-*` 형식의 15개 색상 에셋 중 무작위로 선택 |
| 이동 여부   | 고정형 필드                                               |

## 동작

| 조건                               | 동작      | 결과                             |
| ---------------------------------- | --------- | -------------------------------- |
| 오브젝트 진입                      | 웜홀 이동 | 반대편 웜홀 위치로 오브젝트 이동 |
| 반대편 위치를 다른 오브젝트가 점유 | 이동 거절 | 진입 전 위치 유지                |

## 관계

| 대상             | 관계       | 결과                                    |
| ---------------- | ---------- | --------------------------------------- |
| 오브젝트         | `relocate` | 반대편 위치로 이동                      |
| `FIELD-WORMHOLE` | `linked`   | 쌍 식별자가 같은 다른 웜홀과 `1:1` 연결 |

## 규칙

- `FIELD-WORMHOLE`는 이동하거나 밀리지 않는다.
- 웜홀을 사용하는 맵에는 완성된 웜홀 쌍이 하나 이상 존재할 수 있다.
- 에디터에서 연속으로 배치한 두 웜홀이 하나의 고정된 쌍을 이루며 별도 쌍 선택은 필요하지 않다.
- 새 쌍은 아직 사용하지 않은 이미지 중 하나를 무작위로 사용하며, 15개 이미지가 모두 사용된 뒤에는 기존 이미지를 다시 사용할 수 있다.
- 같은 쌍의 두 웜홀은 선택된 이미지 번호를 공유하며, 에디터와 라이브 화면에서 같은 이미지로 표시한다.
- 완성된 쌍의 한쪽 웜홀을 제거하면 반대편 웜홀과 쌍 정보도 함께 제거한다.
- 오브젝트는 웜홀 진입과 반대편 위치 이동을 하나의 이동으로 수행한다.
- 반대편 위치를 다른 오브젝트가 점유하면 웜홀 진입을 거절한다.
