# 웜홀

`FIELD-WORMHOLE` · 필드

진입한 오브젝트를 고정된 반대편 웜홀 위치로 이동시키는 필드.

## 기본 정보

| 항목 | 값 |
|---|---|
| 블록명 | 웜홀 |
| 식별자 | `FIELD-WORMHOLE` |
| 키 | `field.wormhole` |
| 블록 이미지 | <!-- 작성 --> |
| 연결 방식 | 고정된 `1:1` 쌍 |
| 배치 수량 | `0`개 또는 `2`개 |
| 이동 여부 | 고정형 필드 |

## 동작

| 조건 | 동작 | 결과 |
|---|---|---|
| 오브젝트 진입 | 웜홀 이동 | 반대편 웜홀 위치로 오브젝트 이동 |
| 반대편 위치를 다른 오브젝트가 점유 | 이동 거절 | 진입 전 위치 유지 |

## 관계

| 대상 | 관계 | 결과 |
|---|---|---|
| 오브젝트 | `relocate` | 반대편 위치로 이동 |
| `FIELD-WORMHOLE` | `linked` | 맵의 다른 한 웜홀과 `1:1` 연결 |

## 규칙

- `FIELD-WORMHOLE`는 이동하거나 밀리지 않는다.
- 웜홀을 사용하는 맵에는 웜홀이 정확히 두 개만 존재한다.
- 두 웜홀의 위치가 하나의 고정된 쌍을 이루며 별도 페어 선택은 필요하지 않다.
- 오브젝트는 웜홀 진입과 반대편 위치 이동을 하나의 이동으로 수행한다.
- 반대편 위치를 다른 오브젝트가 점유하면 웜홀 진입을 거절한다.

## 시각 표현

| 상태 또는 이벤트 | 표현 |

| 기본 | 웜홀 필드 이미지와 쌍 식별 오버레이 |
| 이동 | 진입 위치와 반대편 위치 간 이동 |
