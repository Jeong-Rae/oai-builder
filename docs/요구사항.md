# 요구사항

## Use Cases

### 그래픽

- 게임 시스템은 `tile` 타일을 가로 20개, 세로 10개로 배치한 배경을 렌더링해야 한다.
- 게임 시작이 발생하면, 게임 시스템은 배경의 좌하단 타일에 플레이어 캐릭터 에셋을 렌더링해야 한다.
- 게임 시작이 발생하면, 게임 시스템은 임의의 위치에 상자 5개를 생성해야 한다.
- 게임 시작이 발생하면, 게임 시스템은 화면 우측 상단에 출구를 렌더링해야 한다.
- 게임 시스템은 4개의 프레임으로 구성된 출구를 렌더링해야 한다.
- 플레이어가 출구에 도착하면, 게임 시스템은 출구 프레임을 1프레임부터 4프레임까지 순차적으로 렌더링해야 한다.

### 조작법

- 플레이어가 방향키의 상/하/좌/우 키를 입력하면, 게임 시스템은 플레이어 캐릭터를 입력 방향으로 인접한 타일 위로 이동해야 한다.
