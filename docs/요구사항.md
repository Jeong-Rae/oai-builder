# 요구사항

## Use Cases

### 그래픽

- 게임 시스템은 `tile` 타일을 가로 9개, 세로 9개로 배치한 배경을 렌더링해야 한다.
- 게임 시작이 발생하면, 게임 시스템은 배경의 좌하단 타일에 플레이어 캐릭터 에셋을 렌더링해야 한다.
- 게임 시작이 발생하면, 게임 시스템은 임의의 위치에 상자 5개를 생성해야 한다.
- 게임 시작이 발생하면, 게임 시스템은 화면 우측 상단에 출구를 렌더링해야 한다.
- 게임 시스템은 4개의 프레임으로 구성된 출구를 렌더링해야 한다.
- 플레이어가 출구의 인접한 칸에 도착하면, 게임 시스템은 출구 프레임을 1프레임부터 4프레임까지 순차적으로 렌더링해야 한다.

### 조작법

- 게임 시스템은 상(`↑`), 하(`↓`), 좌(`←`), 우(`→`) 컨트롤 각각의 소유자를 추적해야 한다.
- 방향 컨트롤의 소유자는 해당 방향으로 행동해야 한다.
- 방향 컨트롤의 소유자가 방향키를 입력하고 진행 방향의 인접한 타일에 일반 오브젝트가 없으면, 게임 시스템은 소유자 오브젝트를 해당 타일로 이동해야 한다.
- 방향 컨트롤의 소유자가 방향키를 입력하고 진행 방향의 인접한 타일에 일반 오브젝트가 있으면, 게임 시스템은 두 오브젝트의 위치를 유지해야 한다.
- 방향 컨트롤의 소유자가 방향키를 입력하고 진행 방향의 인접한 타일에 일반 오브젝트가 있으면, 게임 시스템은 이번 행동에 사용한 방향 컨트롤의 소유권을 해당 일반 오브젝트로 이전해야 한다.
- 방향 컨트롤의 소유권이 이전된 후 해당 방향키가 입력되면, 게임 시스템은 새 소유자 오브젝트가 해당 방향으로 행동하게 해야 한다.
