# 웜홀 애니메이션 중 에셋 화질 저하 조사

## 현상

오브젝트가 웜홀을 이용할 때 약 800ms 동안 실행되는 진입·도착 애니메이션에서 다른 에셋의 화질도 일시적으로 저하된다. 애니메이션이 끝나면 화질이 정상으로 돌아온다.

관련 구현은 `src/game/scenes/game/view.ts`의 `playWormhole()`이다. 이 함수는 Web Animations API로 오브젝트의 `.entityLayer`를 애니메이션한다. `.entityLayer`에는 오브젝트 이미지와 방향 표시 이미지가 함께 들어 있다.

## 조사 환경

- 기준 브랜치: `main`의 `80a730f`
- 진단 브랜치: `test/wormhole-no-scale`
- 진단 워크트리: `/workspaces/openai-builder-worktrees/wormhole-no-scale`
- 조사일: 2026-08-23
- 확인 방법: 사용자가 동일한 웜홀 이동을 실행하고 육안으로 화질 저하 여부를 비교했다.

## 비교 실험 결과

| 실험                     | 활성화한 효과                                                              | 결과                      |
| ------------------------ | -------------------------------------------------------------------------- | ------------------------- |
| 기존 구현                | `clip-path`, `opacity`, `translateY()`, 오브젝트 `scale()`, 웜홀 확대 펄스 | 화질 저하가 나타남        |
| 스케일 제거              | `clip-path`, `opacity`, `translateY()`                                     | 화질 저하가 나타남        |
| Web Animations 전체 제거 | 애니메이션 없이 400ms씩 대기한 뒤 DOM 위치만 변경                          | 화질 저하가 나타나지 않음 |
| `clip-path` 제거         | `opacity`, `translateY()`                                                  | 화질 저하가 나타남        |
| 이동 제거                | `opacity`만 사용                                                           | 화질 저하가 나타나지 않음 |

이 결과로 다음 사항을 확인했다.

1. 원본 이미지 파일, 게임 상태 동기화, DOM 위치 변경은 직접적인 원인이 아니다.
2. `clip-path`는 문제 발생에 필수적인 조건이 아니다.
3. 스케일 제거만으로는 문제가 해결되지 않는다. 다만 스케일만 단독으로 실행하는 실험은 하지 않았으므로, 스케일의 독립적인 영향까지 부정할 수는 없다.
4. 현재 실험에서 화질 저하를 발생시키는 필수적인 차이는 `.entityLayer`에 적용한 `translateY()` 애니메이션이다.

## 원인

`translateY(0)`과 `translateY(18%)` 사이를 보간하면 `.entityLayer`가 프레임마다 비정수 화면 좌표에 배치될 수 있다. 브라우저는 이 레이어의 하위 이미지를 합성된 비트맵으로 이동시키므로, 픽셀 경계가 화면 픽셀과 맞지 않는 프레임에서 오브젝트와 방향 표시 이미지가 함께 재샘플링된다.

이 프로젝트의 게임 에셋에는 `image-rendering: pixelated`가 적용되어 있다. 따라서 비정수 좌표 보간 중의 재샘플링 결과가 흐려지거나 불균일한 픽셀로 더욱 뚜렷하게 보인다.

## 병합 대상 수정

진단 워크트리의 `playWormhole()`은 모든 `transform` 애니메이션을 제거하고 다음 효과만 유지한다.

- `clip-path`: 위아래 방향으로 오브젝트가 사라지고 나타나는 모양을 유지한다.
- `opacity`: 진입과 도착 단계의 페이드 효과를 유지한다.
- 각 단계의 400ms 실행 시간과 기존 easing을 유지한다.

오브젝트의 축소와 웜홀 이미지의 확대 펄스도 `transform`을 사용하므로 병합 대상에서는 제거했다. 사용자는 `translateY()`를 제거하고 `opacity`만 유지한 비교 실험에서 화질 저하가 나타나지 않는다고 확인했다. 이후 사라짐·등장 형태를 유지하기 위해 `clip-path`를 복원했으며, 이 상태를 메인 브랜치 병합 대상으로 준비했다.

## 다음 작업

2. 웜홀 확대 펄스가 필요하면 `.entityLayer`와 분리된 효과 오브젝트로 구현하고, 실제 웜홀 이미지나 오브젝트 레이어에는 `transform`을 적용하지 않는다.
3. 위치 이동 효과가 반드시 필요하면 퍼센트 기반 `translateY()` 대신 정수 픽셀 단계 애니메이션이나 별도의 효과 오브젝트를 검토하고, 여러 화면 크기에서 화질을 다시 확인한다.
